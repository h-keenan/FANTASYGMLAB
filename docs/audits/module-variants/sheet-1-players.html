Module variants 1/4: Player card + PQV sheet

Side-by-side variants for choosing. 390px frames, real tokens (liquid-glass dark, cyan accent, gold highlight). Pick V1 / V2 / V3 per topic.

1a. Player row / card: compact vs expanded

Real FantasyDesk fields: name, position badge, team, age, projection, trade value gauge, trend, injury/bye badges. Fantasy Sim swaps numeric OVR for a letter grade and adds ADP + symbol badges (star, boom, injury cross). Each frame shows FantasyDesk on top, Fantasy Sim below.

V1 · Inline accordion row

Pitch Two-line row; tap the chevron and the row grows in place to a stat grid, badges and one action.

Trade-off Expanding pushes neighbours down; only one open at a time to stay calm.

Pitch Classic: sticky header, 5 underlined text tabs, content scrolls beneath.

Trade-off Header costs ~110px; tabs overflow on 360px phones (Scouting scrolls in).
