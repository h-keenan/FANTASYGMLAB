2. Hero + compact module stack (Today, Team, Sim Home)

Same skeleton on all three pages: one hero with one primary action, then compact modules. Today = lineup/trades/waivers/matchup; Team = roster health, depth, picks, power; Sim Home = draft clock, roster, standings, schedule. Compact frame shows Today, expanded frame shows Sim Home; Team follows the identical pattern.

V1 · Hero + accordion stack

Pitch One hero action on top, then full-width compact modules (one line + chip). Tap a module and it opens inline.

Trade-off Longest scroll; 6+ modules push content below the fold.
