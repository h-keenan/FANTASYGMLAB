Recommend V2 (players-first status header). The compact player row is the approved unit, so building the page around it (who needs attention) is the least new design and answers "what do I do now" with names and numbers; it still has a single gold action. V1 is the safer fallback if you want it closest to the shipped Sim CompactModule list.
