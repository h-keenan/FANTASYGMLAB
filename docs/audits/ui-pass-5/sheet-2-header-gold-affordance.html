6. Module trailing control

Today a module ends in one of: "→" (navigate), "+" / "–" (expand), "Open →", "All →", "+ All →" (both), "Full analysis" next to a "+", "View all" next to a "–", plus "Review" button beside a "+" on the Top priority card. A user cannot tell if a tap expands or leaves the page.

RECOMMENDEDV1: Two glyphs, never text

Expand = chevron that rotates; navigate = arrow. Row text links ("Open", "All", "View all") become the destination arrow only; a module is one or the other, never both.
