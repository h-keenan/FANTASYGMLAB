Smart floating pill: 3 variants

All use option B glass tokens and the single sticky bottom stack. Context actions (3 to 5, one primary) come from the page via one hook. V1 two rows in one capsule (global tabs on top, page row below). V2 one row: global collapses to icons, page segment morphs in. V3 two capsules: slim page strip floating above the global pill. Page-family tab rows move into the pill and the duplicate top row is removed.
