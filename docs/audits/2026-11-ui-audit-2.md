# UI audit 2 (2026-11): sizing, accessibility, ease of use, layout, polish

Scope of this pass: **Fantasy Sim, web**, rendered at **360 / 375 / 390 / 430px, dark and light**, 12 screens each (game hub, Home,
Team, Players, Trades inbox + builder, League standings / scores / feed / teams / players, More): 96 renders, DOM-checked by
`scripts/sim_layout_playwright/ui_audit.mjs` (horizontal overflow, tap targets under 44px, unnamed controls, truncated names,
text under 11.5px, text contrast against the composited background, unnamed dialogs, button-height spread). Mobile was reviewed
**statically** (source greps + the existing typography guard), not rendered. **Not covered yet:** the main app outside Fantasy
Sim, 200% text scaling, a screen-reader pass, keyboard-overlap on inputs, real-device safe areas. Those are listed under "Next".

Re-run: `PW_CORE=.../playwright-core/index.mjs BASE=http://localhost:3197 node scripts/sim_layout_playwright/ui_audit.mjs [screen]`
(env `WIDTHS`, `THEMES`, `OUT`).

## Clean (verified, keep it that way)

- **No horizontal overflow** on any screen at any of the 4 widths in either theme (the overflow guard holds).
- **Every interactive element has an accessible name; every dialog has a name.** (0 unnamed controls, 0 unnamed dialogs.)
- **TapForWhy ("Why: Overall 99")** measures 26px tall but carries a 10px-inset hit area (`.ui-why::after`): 46px effective. Not a defect.
- Contrast on the composited background: only 3 distinct text samples under AA, all tiny tinted chips (see M2).

## Findings, ranked

### High

**H1. Control sizes differ menu to menu** (coridian_: "we don't want sizing to be different on one menu compared to another").
Measured button heights before: 26 / 36 / 38 / 40 / 44 / 52 / 56 ... Offenders: `SimIconButton` 40px (web + app) next to the
44px header icon buttons; the new notification bell 40px with different chrome (a bordered glass circle) beside borderless header
icons; `.sim-team-chip` 36px; app `Button size="sm"` **36px** while web `sm` is 44px (`--touch-target-min`).
*Fixed here:* `SimIconButton` default 44 (web + app), bell uses the header's shared `SIM_ICON_BTN` / `SIM_ICON_STYLE`, team chip
`min-height: var(--touch-target-min)`, app `Button` sm 44 (web parity). Heights after: 44 dominates (1338 of ~1750 buttons); 38px remains
only on "open player" buttons inside cards (see M3).

**H2. Micro text.** PlayerListRow stat labels (PROJ / OVR / EDGE / ADP) were **9px**; 54 Tailwind literals under 12px across web
(mobile has a 12px guard, web had none). *Fixed here:* stat labels 11px; added `lib/uiSizingGuard.test.ts`, a ratchet on 8-10px
literals (baseline 32, only goes down). Still open: the remaining 32 (draft hero / grid, SuggestedDrop, ToneBadge xs).

**H3. Stat columns jump between rows.** In the lineup and bench lists PROJ and OVR sat in different columns depending on whether
a row had an EDGE chip (right-justified block, variable width). *Fixed here:* `PlayerListRow alignColumns` (set by `SimPlayerLine` /
`SimRosterLine`): the block is left-anchored at a fixed width (`PLAYER_LIST_ALIGNED_WIDTH`), slot widths widened for 11px labels.
Before / after: `before-team-dark-390.png`, `after-team-dark-390.png`.

### Medium

- **M1. Names that still truncate at 360px:** score-card team names (`line-clamp-2`, "Waiver Wire Warriors"), and the player name in the Home bye alert
  ("Colton Rhodes Jr." overflows its block). *Fixed:* score-card names wrap (no clamp). *Open:* the Home alert's chip block (PlayerName
  shortens, the wrapper `span.block.min-w-0` still overflows by a few px at 360).
- **M2. Contrast under AA on tinted chips:** rank "3" in light (4.10:1) and "L1" (4.31 light / 4.45 dark) on tone-tinted badges (League,
  More). Fix is a darker/lighter text tone for `ToneBadge` xs on tinted fills; not done here (needs a token pass in both themes).
- **M3. "Open player" buttons inside cards are 38px tall** (waiver / bye alert / suggested drop cards: `button.block.min-w-0`,
  `button.min-w-0.flex-1`). Needs `min-height: var(--touch-target-min)` on the shared card player button.
- **M4. No web guards** for text floor or tap targets existed (mobile had the typography guard). *Added* the text ratchet; a tap-target
  guard is the next one (the harness already measures them).
- **M5. Light theme chrome:** the bell was a bordered white circle among borderless icons. *Fixed* with H1.

### Low / polish

- Slot-label column in lineup rows leaves a wide gap on 360px (the slot pill is centered in 52px, the avatar starts at ~120px).
- Position badge `sm` is 11px (kept; it is a label, not body text).
- The floating game orb overlaps the right edge of the last visible stat chip on Team (by design, but EDGE chips clip behind it; consider 72px bottom padding on lists).
