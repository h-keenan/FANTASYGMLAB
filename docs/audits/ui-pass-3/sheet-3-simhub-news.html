6. News / feed module

NewsContent is a 278-line page with no SectionHeading, no CompactModule and 11 inline-style blocks; the player news tab (PlayerNewsTab) prints Loading text. News is the main reason to return daily, so it should be a shared feed row.

RECOMMENDEDV1 Roster-first digest

News grouped by your players first, then league. Each item states what it means (Start / Watch / Hold).

Trade-off: needs an impact line per item; the model must produce it reliably or leave it blank.
