8. Desktop layout

Only 2 pages use page-shell-wide (Matchup, sample league); default page-shell is 48rem so every other page is a phone column floating on a wide screen; 1 of 34 *Content components has a lg: grid. Mobile is 95% of users, so this is lower priority and must not fork components. Frames are wireframes (not 390px UI).

RECOMMENDEDV1 Master-detail

List left, detail right; picking a row fills the right pane with the same sheet content as phone (peek -> full).

Trade-off: needs the PQV sheet to render as a pane, not only a bottom sheet.
