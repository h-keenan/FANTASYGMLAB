# UI pass 3 (2026-11-14): audit of main after the day's changes, and variant sheets

Trigger: coridian_ asked for another big UI pass with potential versions, once everything from today is live. Method: code and test
reading of the shipped pages on `origin/main` (a9bec147), grep counts over `web-next/src` and `mobile/src`, a read of every prior
2026-11 audit, and a headless-Chrome look at the live public site (`app.fantasygmlab.com` landing, `/sample-league`, `/methodology`,
390 wide, iPhone UA, no sign-in). Docs and mockups only, no product code changed.

Limits: signed-in pages (Today, Team, Players, Waivers, Matchup, Trades, League, Draft, GM Plan, Portfolio, Account, all of Fantasy Sim)
cannot be seen without an account, so they were audited from code, tests and the earlier fixture scans
(`2026-11-module-templates-rollout.md`, `2026-11-sim-ui-pass.md`), not re-shot. Headless Chrome will not render narrower than about 500px,
so the 390 live captures were clipped on the right and were used only for vertical structure. No on-device check of the app was done.
Counts are files (not call sites), tests and stories excluded.

Standing rules applied: never remove information, collapsed modules show real data, one tab row per page, PFPs via shared templates,
J. Surname never ellipsized, no chevron on fully tappable rows, gold only for premium or the one primary action, cyan structure,
liquid glass only, Fantasy Sim shows letter grades never a number, universal smooth motion, multi-factor reasons on advice.
